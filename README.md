# ワイン・テイスティングノート

J.S.A.（日本ソムリエ協会）のテイスティング用語選択用紙をベースにした、単一HTMLファイルで動くデジタル記録ツールです。ビルドやサーバーは不要で、`wine_tasting_note.html` をブラウザで開くだけで使えます。

## 使い方

1. `wine_tasting_note.html` をブラウザで開く。
2. 「記録する」タブで白/赤ワインを選び、外観・香り・味わい・評価・ブドウの各項目をチップで選択してタイトル・コメントを入力し、「この内容を記録する」で保存。
3. 「記録一覧」タブで保存済みの記録を確認・編集・削除。記録を開くとその場で編集フォームになる。

## 主な機能

- **テイスティング記録**：J.S.A.用語シート準拠の項目をチップ選択形式で入力（全項目、複数選択可）。
- **一覧・編集**：保存済みの記録を開くとそのまま編集でき、「更新」で保存。
- **採点機能**：外観・香り・味わい・評価の各グループに正解数を入力すると配点（外観×2点／香り×2点／味わい×2.3点／評価×3点）で自動計算。収穫年・生産地（国）・主なブドウ品種は正解/不正解の判定（国が不正解の場合、収穫年も0点扱い）。合計点も自動表示。
- **CSVエクスポート/インポート**：記録一覧から全記録をCSVで書き出し・読み込み可能。

## データの保存先

すべての記録は `localStorage` に保存されます（サーバーへの送信なし）。ブラウザ・端末をまたいでデータを持ち運びたい場合はCSVエクスポート/インポートを使用してください。

## ファイル構成

```
wine_tasting_note.html          アプリ本体（HTML/CSS/JS 一体型）

```
